# Contributing

This repository is published from Ronana's internal source, so changes made
here cannot be merged. Pull requests are closed automatically.

Issues are welcome:

- **Bug or problem:** open an issue with the template. Include the command you
  ran and the output, with any links or ids you would rather keep private
  removed.
- **Idea or request:** open an issue and describe what you are trying to do.
- **Security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

Account, billing and credit questions go to [Ronana support](https://ronana.ai/support),
not here.
